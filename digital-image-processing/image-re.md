# 图像复原与重建

图像复原与重建的目标是恢复退化的图像或从投影数据重建图像。与图像增强不同，图像复原是客观的，以图像退化的数学或概率模型为基础；而图像增强是主观的、面向问题的。

| 概念	| 区别 |
| ---- | ---- |
| 图像复原	| 以退化模型为基础，目标是恢复原始图像 |
| 图像增强	| 以主观偏好为基础，目标是改善视觉效果 |
## 图像退化/复原处理的一个模型
1. 退化模型
模型公式：
$$g(x,y) = h(x,y) \star f(x,y) + \eta(x,y)$$
其中：
$f(x,y)$：原始图像
$h(x,y)$：退化函数（空间域）
$\eta(x,y)$：加性噪声
$g(x,y)$：退化后的图像（观测图像）
$\star$：卷积运算
- 频率域表示：
$$G(u,v) = H(u,v)F(u,v) + N(u,v)$$

2. 复原过程
给定 $g(x,y)$ 和关于 $h$ 和 $\eta$ 的某些知识，估计原始图像 $\hat{f}(x,y)$
复原方法越接近理想情况，估计越精确
## 噪声模型
### 噪声的空间和频率特性
- 噪声空间特性：与图像空间坐标相关;独立于像素时称为不相关噪声
- 噪声频率特性：指噪声在傅里叶域中的频率内容，如白噪声的傅里叶频谱是常数
### 一些重要的噪声概率密度函数（PDF）
| 噪声类型	| PDF公式	| 参数	| 特点 |
| ---- | ---- | ---- | ---- |
| 高斯噪声	| $p(z) = \frac{1}{\sqrt{2\pi}\sigma} e^{-(z-\bar{z})^2/2\sigma^2}$	| 均值 $\bar{z}$，方差 $\sigma^2$	| 最常用，模型简单 |
| 瑞利噪声	| $p(z) = \frac{2}{b}(z-a)e^{-(z-a)^2/b}$	| $a,b$ 参数	| 非对称分布 |
| 爱尔兰（伽马）噪声	| $p(z) = \frac{a^b z^{b-1}}{(b-1)!}e^{-az}$	| $a>0, b$ 为正整数 |	非对称分布 |
| 指数噪声	| $p(z) = ae^{-az}$ |	$a>0$	| 爱尔兰噪声的 $b=1$ 特例 |
| 均匀噪声 |	$p(z) = \frac{1}{b-a}$	| $a,b$ 参数 |	简单分布|
| 椒盐噪声 |	脉冲噪声，像素值为0或255 |	概率 $P_p, P_s$	| 产生黑白点噪声 |
### 周期噪声
- 来源：图像采集过程中的电气或机电干扰
- 特点：频率域中表现为能量脉冲
- 处理：使用带阻滤波器或陷波滤波器在频率域中去除
### 估计噪声参数
从图像中选取背景区域（灰度变化缓慢）来估计噪声的均值和方差，周期噪声的参数可通过观察傅里叶频谱来估计
## 只存在噪声的复原——空间滤波
当退化函数 $h(x,y) = \delta(x,y)$ 时（即无模糊），退化模型简化为：
$$g(x,y) = f(x,y) + \eta(x,y)$$
### 均值滤波器
| 滤波器类型	| 原理	| 特点 |
| ---- | ---- | ---- |
| 算术均值滤波器	| $f(x,y) = \frac{1}{mn}\sum_{(s,t)\in S_{xy}} g(s,t)$	| 平滑噪声，但会模糊图像|
| 几何均值滤波器	| $f(x,y) = \left[\prod_{(s,t)\in S_{xy}} g(s,t)\right]^{1/mn}$	| 平滑效果与算术均值相当，但丢失的细节更少|
| 谐波均值滤波器	| $f(x,y) = \frac{mn}{\sum_{(s,t)\in S_{xy}} \frac{1}{g(s,t)}}$	| 对盐粒噪声效果好，对胡椒噪声效果差|
| 逆谐波均值滤波器	 | $f(x,y) = \frac{\sum_{(s,t)\in S_{xy}} g(s,t)^{Q+1}}{\sum_{(s,t)\in S_{xy}} g(s,t)^{Q}}$	| $Q$ 为正时消除胡椒噪声，$Q$ 为负时消除盐粒噪声 |

### 统计排序滤波器
| 滤波器类型	| 原理	| 特点 |
| ---- | ---- | ---- |
| 中值滤波器	| 用邻域内像素的中值代替中心像素 |	对椒盐噪声效果极好，产生模糊较少 |
| 最大值滤波器	| 用邻域内像素的最大值代替中心像素 |	去除胡椒噪声，但会提取亮区域 |
| 最小值滤波器	| 用邻域内像素的最小值代替中心像素	| 去除盐粒噪声，但会提取暗区域 |
| 中点滤波器	| 用邻域内像素的最大值和最小值的平均值	| 结合了排序和平均，适用于高斯和均匀噪声 |
### 自适应滤波器
- 自适应局部降噪滤波器：根据局部统计特性（均值和方差）调整滤波强度，在噪声方差大的区域滤波强度大，在边缘区域滤波强度小
- 优点：保持边缘的同时有效降噪，性能优于均值滤波器
## 使用频率域滤波降低周期噪声
### 陷波滤波器
- 定义：阻止（或允许）特定频率点附近的频率分量
#### 巴特沃斯陷波滤波器
$$ H(u,v) = \frac{1}{1 + [D_0^2 / D_1(u,v)D_2(u,v)]^n} $$
, 其中 $D_1, D_2$ 是到陷波中心的距离
#### 最优陷波滤波
- 通过最小化局部方差来估计噪声模式，然后从图像中减去噪声
- 适用于噪声模式未知或非平稳的情况
## 线性位置不变退化
1. 线性退化：满足加性和同质性的退化系统，叠加原理成立。
2. 位置不变（空间不变）
退化函数 $h$ 在图像中任何位置具有相同的形式，仅取决于坐标差：
$$h(x,y,\alpha,\beta) = h(x-\alpha, y-\beta)$$
3. 常见退化模型
- 运动模糊：由相机与物体之间的相对运动引起
- 大气湍流模糊：由大气扰动引起
- 散焦模糊：由镜头失焦引起
## 估计退化函数
| 方法	| 原理	| 适用场景 |
| ---- | ---- | ---- |
| 观察法	| 选择图像中已知结构的区域，从退化图像中估计 $H$	| 无先验知识时|
| 试验法	| 使用与退化系统相同的设备获取冲激图像来估计 $H$	| 可重复实验时|
| 建模法	| 基于物理原理建立退化模型 |	已知退化机理时 |
### 常见建模法
- 大气湍流模型： $H(u,v) = e^{-k(u^2+v^2)^{5/6}}$
- 运动模糊模型： $H(u,v) = \frac{T}{\pi(ua+vb)} \sin[\pi(ua+vb)] e^{-j\pi(ua+vb)}$
## 逆滤波
1. 基本原理
直接对退化模型求逆：
$$\hat{F}(u,v) = \frac{G(u,v)}{H(u,v)}$$
如果 $H(u,v)$ 在某个频率处为零或非常小，则 $\hat{F}$ 在这些频率处被噪声主导
2. 问题与局限
- 噪声放大：当 $H(u,v)$ 很小时，噪声项 $N(u,v)/H(u,v)$ 被严重放大
- 解决方法：将滤波限制在 $H(u,v)$ 不为零的频率附近
## 最小均方误差（维纳）滤波
1. 基本原理
- 目标：使恢复图像 $\hat{f}$ 与原始图像 $f$ 之间的均方误差最小
- 频率域公式：
$$\hat{F}(u,v) = \left[\frac{1}{H(u,v)} \cdot \frac{|H(u,v)|^2}{|H(u,v)|^2 + S_\eta(u,v)/S_f(u,v)}\right] G(u,v)$$
, 其中：
$S_\eta(u,v) = |N(u,v)|^2$：噪声功率谱
$S_f(u,v) = |F(u,v)|^2$：原图像功率谱
2. 特点
- 当噪声为0时，退化为逆滤波
- 在噪声存在时，自动抑制噪声较大的频率分量
- 需要知道噪声和原图像的功率谱（通常用常数估计）
3. 近似形式
当噪声功率谱未知时，可用常数 $K$ 近似：
$$\hat{F}(u,v) = \left[\frac{1}{H(u,v)} \cdot \frac{|H(u,v)|^2}{|H(u,v)|^2 + K}\right] G(u,v)$$
## 约束最小二乘方滤波
1. 基本原理
- 目标：最小化二阶导数（拉普拉斯）的功率，约束条件为噪声方差
- 频率域公式：
$$\hat{F}(u,v) = \left[\frac{1}{H(u,v)} \cdot \frac{|H(u,v)|^2}{|H(u,v)|^2 + \gamma |P(u,v)|^2}\right] G(u,v)$$
其中：
$P(u,v)$：拉普拉斯算子的傅里叶变换
$\gamma$：调节参数
2. 与维纳滤波的比较
- 维纳滤波需要知道噪声和原图像的功率谱
- 约束最小二乘方滤波只需要知道噪声的方差和均值
## 几何均值滤波
1. 公式
$$\hat{F}(u,v) = \left[\frac{1}{H(u,v)}\right]^\alpha \left[\frac{|H(u,v)|^2}{|H(u,v)|^2 + \beta S_\eta/S_f}\right]^{1-\alpha} G(u,v)$$

2. 特殊参数
| $\alpha$ 值	| 对应的滤波器 |
| ---- | ---- |
| $\alpha = 1$	| 逆滤波|
| $\alpha = 0$	| 维纳滤波|
| $\alpha = 0.5$ |	两个滤波器的几何平均|
## 由投影重建图像
从一维投影数据重建二维图像，重要应用：计算机断层成像（CT）
### X射线计算机断层成像（CT）原理
X射线源和检测器围绕物体旋转，收集多个角度的投影数据，通过重建算法生成二维剖面图像
### 投影和雷登变换
- 雷登变换：将二维函数 $f(x,y)$ 映射到其在各个角度上的线积分
- 投影 $g(\rho, \theta)$：沿角度 $\theta$ 方向、距离原点 $\rho$ 处的线积分
### 反投影
- 简单反投影：将每个投影均匀地“涂抹”回图像平面
- 问题：产生星形伪影，图像模糊
### 傅里叶切片定理
- 核心原理：一个投影的傅里叶变换等于该投影在频率域中通过原点的切片
- 意义：将投影数据与傅里叶变换联系起来
### 使用平行射线束滤波反投影重建
- 滤波反投影（FBP）：先对投影数据进行滤波，再进行反投影
- 滤波器：斜坡滤波器（Ram-Lak滤波器）
  - 优点：消除星形伪影，重建质量高
### 使用扇形射线束滤波反投影重建
- 实际CT扫描仪使用扇形而非平行射线束，需要将扇形数据重排为平行数据，或使用扇形重建公式
# 核心要点总结
- 退化模型：$g = h \star f + \eta$ 是图像复原的基础，$h$ 是退化函数，$\eta$ 是噪声
- 噪声模型：高斯噪声最常见，椒盐噪声用中值滤波器效果最好
- 空间滤波：均值滤波器平滑噪声，统计排序滤波器处理脉冲噪声，自适应滤波器兼顾去噪和保边
- 频率域滤波：陷波滤波器专门用于去除周期噪声
- 逆滤波：直接求逆但噪声放大严重，需限制频率范围
- 维纳滤波：最小均方误差准则，需要噪声和图像功率谱信息
- 约束最小二乘方滤波：只需噪声方差信息，比维纳滤波更实用
- 由投影重建：雷登变换、傅里叶切片定理、滤波反投影是CT重建的核心理论
