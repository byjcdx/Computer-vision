> 本章介绍数字图像处理的基本概念，包括人类视觉系统、光和电磁波谱、图像感知与获取、取样与量化、像素间的基本关系以及数字图像处理所用的基本数学工具。

## 视觉感知要素
1. 人眼的结构
- 基本构造：人眼近似球体（直径约20mm），由三层膜包裹：角膜与巩膜（外层）、脉络膜（中层）和视网膜（内层）。
- 关键部件：
  - 虹膜与瞳孔：虹膜控制瞳孔大小（2~8mm），调节进入人眼的光量。
  - 晶状体：由纤维细胞层组成，负责聚焦，随年龄增长会变黄。
  - 视网膜：布满了后部内壁，包含两类光感受器：
  - 锥状体：600~700万个，主要分布在中央凹，对颜色高度敏感，负责明视觉（亮视觉）。
  - 杆状体：7500~15000万个，分布面积大，无色觉，对低光照度敏感，负责暗视觉（微光视觉）。
2. 人眼中图像的形成
- 聚焦机制：与照相机不同，人眼通过改变晶状体的形状（压扁或加厚）来改变焦距，从而在不同距离上正确聚焦。
- 成像过程：来自物体的光在视网膜上成像，光感受器（锥状体和杆状体）的相对激励作用将辐射能量转换为电脉冲，最终由大脑解码。
3. 亮度适应与辨别
- 亮度适应：视觉系统能够适应的光强等级范围很宽（约10^10级），但不能同时工作。它通过改变整体灵敏度（亮度适应水平）来完成较大的变化。
- 亮度辨别能力：
  - 韦伯比：用于衡量亮度辨别能力，定义为ΔI_c / I（背景照射为I时50%时间可辨别的照射增量）。韦伯比越小，亮度辨别能力越好。
  - 特性：在低照明级别（暗视觉），韦伯比大，辨别能力较差；在高照明级别（明视觉），韦伯比小，辨别能力显著改善。
- 同时对比：一个区域的感知亮度并不只取决于其灰度，还会受背景亮度影响（如背景变亮会使得中心方块看上去变暗）。
- 马赫带：视觉系统在灰度级边界处会产生“下冲”或“上冲”现象，导致感知亮度与实际灰度不符。
- 光学错视：人眼可能感知到不存在的信息或错误地感知物体的几何特点。

## 图像感知与获取
### 观点与结论
- 图像获取的核心原理：大多数图像由“照射”源和“场景”元素对光能的反射或吸收产生。照射能量可被物体反射（如光从表面反射）或透过物体发射（如X射线穿过人体）。
- 三种主要传感器配置：图像感知通过单个传感器（需机械运动）、条带传感器（内嵌一排传感器，一次生成一行）和阵列传感器（二维排列，直接成图）三种配置实现。
- 成像的数学模型：图像函数 $f(x, y)$ 由两个分量乘积构成：入射分量 $i(x, y)$（照射到场景的光源能量）和反射分量 $r(x, y)$（被物体反射的能量）。在透射成像中，反射分量由透射系数代替。 $f(x, y)$ 是非负且有限的。
### 自问自答
- 问：什么是单个传感器成像，它有什么优缺点？
  - 答：单个传感器成像（如光二极管）需要传感器与成像区域之间有 $x$ 和 $y$ 方向的相对位移。例如，将底片装在鼓上，通过鼓的转动和传感器在引导螺杆上的线性运动来生成二维图像。其优点是成本低、可获得高分辨率图像（因为机械运动可精确控制），但主要缺点是速度慢且不便携带。

- 问：条带传感器和阵列传感器在成像原理上有何主要区别？
  - 答：条带传感器（如平板扫描仪）在一个方向上内嵌一排传感器，通过垂直于条带方向的运动来获取二维图像，一次生成一行。阵列传感器（如CCD芯片）则将传感器以二维阵列形式排列，将能量聚焦到阵列表面即可直接得到一幅完整的二维图像，无需运动。阵列传感器是数字摄像机的主要排列方式，优点是不需要机械运动。

- 问：什么是成像模型中的入射分量和反射分量？它们的取值范围是什么？
  - 答：成像模型 $f(x, y) = i(x, y) r(x, y)$ 中，入射分量 $i(x, y)$ 是照射到场景的光源能量，其取值范围为 $0 \le i(x, y) < \infty$ 。反射分量 $r(x, y)$ 是被物体反射的照射量，其取值范围为 $0 \le r(x, y) \le 1$，其中 0 表示全吸收，1 表示全反射。在透射成像（如X射线）中，需用透射系数代替反射函数，但取值范围相同。

- 问：单个传感器如何通过机械运动生成二维图像？
  - 答：以高精度扫描的鼓式扫描仪为例，底片装在鼓上，鼓的机械转动在一个方向上产生位移（如x方向），传感器安装在产生垂直运动的引导螺杆上（如y方向）。鼓内含有光源，光通过胶片时，因胶片密度变化而调制光强，传感器产生相应的电压变化，再经数字化处理转换为图像灰度。

- 问：环形条带传感器在医学成像中有什么应用？
  - 答：在医学和工业成像中，环形条带传感器用于获取三维物体的剖面（“切片”）图像。其原理是旋转X射线源提供照射，对面的X射线敏感传感器收集穿过物体的X射线能量。这是计算机轴向断层成像（CAT）的原理。传感器的输出由重建算法处理，转换为有意义的剖面图像。通过物体垂直于传感器环的运动，可由图像堆叠形成三维数字物体。

### 术语解释
- 照射源：在图像获取中，指产生照射能量的源头，不仅包括传统可见光，还包括电磁波谱其他波段（如雷达、红外、X射线）以及非传统光源（如超声波、计算机产生的照射模式）。
- 反射/透射：照射能量与场景相互作用的方式。反射指能量从物体表面反向（如光从平坦表面反射）；透射指能量穿过物体（如X射线穿过人体）。获取的图像据此分为反射图像和透射图像。
- CCD（电荷耦合器件）：一种广泛用于数字摄像机和其他光敏设备中的传感器阵列。其每个传感器的响应与投射到传感器表面的光能量的积分成正比，可用于低噪声成像（如天文观测）。
- 数字化仪：图像获取系统中的第二个子系统，其功能是将物理感知设备（如传感器）输出的连续电压波形（模拟信号）转换为数字形式，以便计算机处理。

## 图像取样与量化

> 图像取样和量化是数字图像处理的核心基础环节，其根本目标是将连续的感知数据转换为数字形式。多数传感器的输出是连续电压波形，需要完成数字化。

### 取样和量化的基本概念
1. 基本过程
文档中以沿连续图像中线段AB的一维扫描为例说明了取样和量化的过程：
取样：沿线段AB等间隔地对连续函数进行取样，每个样本的离散空间位置由刻度标记指出
量化：将连续的亮度值范围划分为离散区间（如8个），每个样本根据其值被分配到最近的离散级别
2. 噪声对量化的影响
量化所达到的精度高度依赖于取样信号中的噪声含量。图像噪声表现为图像信息或像素亮度的随机变化。

3. 传感器配置与取样方式的关系

| 传感器类型	| 取样方式	| 精度限制 |
|  ----  | ----  | ----  |
| 单个传感器	| 机械运动激活传感器收集数据	| 原理上精度无限制（机械运动可非常精确） |
| 条带传感器	| 条带中传感器数量决定一个方向，机械转动决定另一个方向	| 一个方向受传感器数量限制 |
| 阵列传感器	| 不需要运动，阵列中传感器数量决定两个方向的取样限制 | 两个方向均受传感器数量限制 |

### 数字图像表示
1. 数学表示
连续图像函数 $f(s,t)$ 经取样和量化后，转换为包含 $M$ 行 $N$ 列的数字图像 $f(x,y)$，离散坐标取整数值：
$$x = 0, 1, 2, \dots, M-1; \quad y = 0, 1, 2, \dots, N-1$$

2. 三种表示方法

| 表示方法	| 特点	| 用途 |
|  ----  | ----  | ----  |
| 函数图	| 以 $(x,y,z)$ 三坐标表达， $z$ 为灰度值	| 处理灰度集时有用 |
| 可视灰度阵列图	| 灰度值归一化到 $[0,1]$，映射为黑/灰/白显示	| 快速观察结果 |
| 矩阵（数值阵列） |	$M \times N$ 矩阵，每个元素为像素值	| 便于处理和算法开发 |

矩阵形式表示为：

$$f(x,y) = \begin{bmatrix} 
f(0,0) & f(0,1) & \cdots & f(0,N-1) \\
f(1,0) & f(1,1) & \cdots & f(1,N-1) \\
\vdots & \vdots & \ddots & \vdots \\
f(M-1,0) & f(M-1,1) & \cdots & f(M-1,N-1) 
\end{bmatrix}$$

4. 坐标系约定
- 原点位于左上角，正 $x$ 轴向下，正 $y$ 轴向右
- 这一约定基于：显示器扫描从左上角开始；矩阵第一个元素按惯例在左上角
5. 正式数学定义
令 $Z$ 和 $R$ 分别表示整数集和实数集：
- 取样：把 $xy$ 平面分为网格，网格中每个单元中心坐标是笛卡儿积 $Z^2$ 中的一对元素
- 量化：函数 $f$ 将灰度值（ $R$ 中的实数）赋给每个特定坐标对 $(x,y)$
5. 灰度级与存储
- 灰度级数 $L$ 通常取 2的整数次幂： $L = 2^k$
- 灰度级区间为 $[0, L-1]$，上限取决于饱和度，下限取决于噪声
- 存储图像所需比特数： $b = M \times N \times k$
  - 当 $M = N$ 时： $b = N^2 k$
- 具有 $2^k$ 个灰度级的图像称为 " $k$ 比特图像"（如256级 = 8比特图像）
6. 动态范围与对比度

| 概念	| 定义 |
|  ----  | ----  |
| 动态范围	| 系统中最大可度量灰度与最小可检测灰度之比 |
| 饱和度	| 超过该值的所有灰度值将被裁剪为最高灰度级 |
| 对比度	| 一幅图像中最高和最低灰度级间的灰度差 |
| 反差比	|最高灰度级与最低灰度级的比率 |

### 线性索引和坐标索引
三维阵列 $(x,y,z)$ 的线性索引公式为：

$$s = x + M(y + Nz)$$

### 空间分辨率和灰度分辨率
1. 空间分辨率
- 定义：图像中可辨别的最小细节的度量
- 通用度量单位：
  - 每单位距离的线对数（广泛使用的定义是单位距离内可分辨的最大线对数量）
  - 每单位距离的点数（如dpi，每英寸点数）
- 关键原则：空间分辨率必须针对空间单位来规定才有意义，图像大小本身不含空间分辨率信息
2. 灰度分辨率
- 定义：灰度级中可分辨的最小变化，即用于量化灰度的比特数
- 影响因素：不仅受噪声和饱和度影响，也受人类感知能力影响
- 常见值：8比特（256级）最常用，16比特用于需要增强特定灰度范围的应用

3. 减少灰度级数的影响
- 伪轮廓：由数字图像平滑区域中的灰度级数不足引起，脊状结构类似地图等高线。通常在16级灰度（4比特）或更少灰度级的图像中十分明显。

5. N与k的相互作用——等偏爱曲线
Huang[1965]的实验研究了同时改变 $N$（样本数）和 $k$（灰度级比特数）对图像质量的影响：
- 实验使用三类图像：细节少（妇女脸庞）、细节中等（摄像师）、细节丰富（人群）
- 结果以 $Nk$ 平面中的等偏爱曲线呈现
- 关键发现：图像细节增多时，等偏爱曲线趋向更加竖直，表明细节丰富的图像只需较少灰度级，但需要较高分辨率
### 图像内插
1. 定义与应用
- 内插是用已知数据估计未知位置数值的过程，常用于图像放大、缩小、旋转和几何校正等任务。
2. 三种内插方法

| 方法	| 原理	| 公式	| 优缺点｜
|  ----  | ----  |  ----  | ---- |
| 最近邻内插	| 在原图像中寻找最邻近像素赋值	| - | 最简单，但会产生严重的直边缘失真 |
| 双线性内插	| 用4个最近邻估计给定位置的灰度 |	$v(x,y)=ax+by+cxy+d$	| 明显优于最近邻，但结果稍模糊；注意：不是线性运算（含 $xy$ 项）|
| 双三次内插	| 用16个最近邻点估计 |	$v(x,y)=\sum_{i=0}^{3}\sum_{j=0}^{3}a_{ij}x^iy^j$	| 保留细节最好，是商业图像编辑程序（如Photoshop）的标准方法 |

### 核心要点总结
- 取样和量化是图像数字化的两大核心步骤，分别处理空间坐标和灰度幅值的离散化
- 数字图像本质上是一个整数矩阵，灰度级取 $2^k$，存储量为 $MNk$ 比特
- 空间分辨率必须基于单位距离才有意义，而灰度分辨率直接由量化比特数决定
- 伪轮廓是灰度级不足的主要视觉表现，通常在16级以下明显出现
- 等偏爱曲线揭示了图像内容与分辨率参数的相互作用：细节丰富的图像更需要高空间分辨率而非多灰度级
- 双三次内插是质量最高的标准内插方法，在保持细节方面优于双线性和最近邻内插
