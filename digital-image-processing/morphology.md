# 形态学图像处理

形态学图像处理是基于数学形态学理论的一种图像处理方法，其基本思想是使用结构元（一种小的形状模板）来探测图像，从而提取图像中目标的形状信息。
形态学处理广泛应用于二值图像和灰度图像，用于图像预处理、目标形状增强、图像分割后的后处理等任务。

## 预备知识
1. 形态学的基本概念
- 形态学：源于生物学中研究动植物形态和结构的学科
- 数学形态学：用集合论方法描述和分析图像形状的工具
- 应用：图像预处理（去噪、形状简化）、目标形状增强、图像分割后的后处理
2. 结构元
- 定义：结构元是一个小的二值图像，用于探测原始图像中的特定形状
- 结构元的元素：由前景像素（值为1）和背景像素（值为0）组成
- 结构元的作用：作为“探针”在图像中移动，检查图像中与结构元匹配的区域
- 结构元的形状：常见形状包括矩形、十字形、圆形、菱形等
- 结构元的大小：通常为奇数尺寸，如 $3 \times 3$、$5 \times 5$ 等
3. 形态学运算的集合论基础
形态学运算基于集合论中的运算，如并集、交集、补集、平移等。给定图像 $A$ 和结构元 $B$，形态学运算通过 $B$ 对 $A$ 进行操作，改变 $A$ 中目标的形状和大小。

## 腐蚀和膨胀
腐蚀和膨胀是形态学处理中最基本的两种运算，所有其他形态学运算都基于它们。

### 腐蚀
- 定义:腐蚀是一种“收缩”或“细化”图像中目标的运算。结构元 $B$ 对图像 $A$ 的腐蚀定义为：
$$A \ominus B = \{ z \mid (B)_z \subseteq A \}$$
其中， $(B)_z$ 表示将结构元 $B$ 平移至位置 $z$， $\subseteq$ 表示包含关系。

- 直观理解
  - 将结构元 $B$ 在图像 $A$ 中逐点移动
  - 当结构元完全位于图像 $A$ 的前景区域内时，保留该位置
  - 结果得到图像中目标的“骨架”或缩小后的版本
- 性质:腐蚀会缩小目标区域，腐蚀会消除小于结构元尺寸的细节，腐蚀会分离通过细小连接相连的目标
- 应用
  - 去除图像中细小的噪声点
  - 分离相互粘连的目标
  - 细化目标（如骨架提取前的预处理）
### 膨胀
- 定义：膨胀是一种“扩张”或“加粗”图像中目标的运算。结构元 $B$ 对图像 $A$ 的膨胀定义为：
$$A \oplus B = \{ z \mid (\hat{B})_z \cap A \neq \emptyset \}$$
其中， $\hat{B}$ 是 $B$ 关于原点的反射， $(\hat{B})_z$ 表示将反射后的结构元平移至位置 $z$。

- 直观理解
  - 将结构元 $B$ 的反射在图像 $A$ 中逐点移动，当结构元与图像的前景区域有交集时，保留该位置，结果得到图像中目标扩张后的版本
- 性质
  - 膨胀会扩大目标区域
  - 膨胀会填充目标内部的孔洞
  - 膨胀会连接相邻的目标
- 应用
  - 填充目标内部的孔洞
  - 连接断裂的目标
  - 加粗目标轮廓
### 对偶性
- 腐蚀和膨胀是对偶的运算，即：
$$(A \ominus B)^c = A^c \oplus \hat{B}$$
$$(A \oplus B)^c = A^c \ominus \hat{B}$$
其中， $A^c$ 是 $A$ 的补集， $\hat{B}$ 是 $B$ 的反射。

- 意义：对图像前景的腐蚀等价于对图像背景的膨胀，反之亦然。

## 开运算与闭运算
开运算和闭运算是基于腐蚀和膨胀的复合运算，分别用于平滑目标轮廓和填充孔洞。

### 开运算
定义：结构元 $B$ 对图像 $A$ 的开运算是先腐蚀后膨胀：
$$A \circ B = (A \ominus B) \oplus B$$

- 性质
  - 开运算会平滑目标轮廓，消除细小的凸起
  - 开运算会断开狭窄的连接
  - 开运算会消除小于结构元尺寸的细节
- 几何解释：开运算的结果是结构元 $B$ 在图像 $A$ 内部平移时所能到达的区域的并集。

### 闭运算
- 定义：结构元 $B$ 对图像 $A$ 的闭运算是先膨胀后腐蚀：
$$A \bullet B = (A \oplus B) \ominus B$$
- 性质
  - 闭运算会平滑目标轮廓，消除细小的凹陷
  - 闭运算会连接狭窄的断裂
  - 闭运算会填充小于结构元尺寸的孔洞
- 几何解释：闭运算的结果是结构元 $B$ 在图像 $A$ 外部平移时所能到达的区域的补集。

### 对偶性
开运算和闭运算也是对偶的：
$$(A \circ B)^c = A^c \bullet \hat{B}$$
$$(A \bullet B)^c = A^c \circ \hat{B}$$

### 应用
- 开运算	去除噪声点、分离粘连目标、平滑轮廓
- 闭运算	填充孔洞、连接断裂目标、平滑轮廓
## 击中-击不中变换
1. 定义
击中-击不中变换是一种用于形状检测的形态学运算。它通过同时匹配前景和背景的特定模式来定位图像中的特定形状。

2. 原理
使用两个结构元： $B_1$（前景结构元）和 $B_2$（背景结构元）
$B_1$ 用于匹配前景形状， $B_2$ 用于匹配背景形状
击中-击不中变换定义为：
$$A \circledast B = (A \ominus B_1) \cap (A^c \ominus B_2)$$
3. 应用
- 在图像中定位特定形状（如角点、交叉点、端点）
- 骨架提取
- 字符识别中的特征定位
## 一些基本的形态学算法
### 边界提取
- 目标：提取图像中目标的边界
- 算法：边界 = 原图像 - 腐蚀后的图像
$$\beta(A) = A - (A \ominus B)$$
### 孔洞填充
- 目标：填充图像中目标内部的孔洞
- 算法：通过条件膨胀实现，从孔洞内部的一个种子点开始，反复膨胀，但限制在目标边界内，直到不再变化
### 提取连通分量
- 目标：提取图像中的各个连通目标
- 算法：通过条件膨胀实现，从目标中的一个种子点开始，反复膨胀，但限制在目标区域内，直到不再变化
### 凸壳
- 目标：计算目标的凸包（包含目标的最小凸多边形）
- 算法：使用多个方向的结构元反复击中-击不中变换和膨胀，直到收敛
### 细化
- 目标：将目标细化为单像素宽的骨架
- 算法：反复使用击中-击不中变换去除边缘像素，直到不再变化
- 条件：保持连通性，不删除端点
### 粗化
- 目标：将目标加粗
- 算法：细化的对偶运算，通过反复膨胀和条件限制实现
### 骨架
- 目标：提取目标的骨架（中轴）
- 算法：通过反复开运算和腐蚀，计算每次腐蚀后与开运算的差
### 裁剪
- 目标：去除骨架上的寄生分支
- 算法：使用击中-击不中变换定位端点，然后反复去除端点像素
## 形态学重建
### 测地膨胀和腐蚀
- 测地膨胀：在掩模图像的限制下进行的膨胀运算，膨胀后的结果必须限制在掩模图像的前景区域内
- 测地腐蚀：在掩模图像的限制下进行的腐蚀运算，腐蚀后的结果必须限制在掩模图像的前景区域内
### 膨胀和腐蚀形态学重建
- 膨胀形态学重建：反复进行测地膨胀，直到不再变化
- 腐蚀形态学重建：反复进行测地腐蚀，直到不再变化
### 应用实例
- 掩模提取	使用标记图像重建掩模中的目标
- 孔洞填充	使用边缘图像作为掩模，填充孔洞
- 边界清除	去除与图像边界接触的目标
- 去除小目标	保留特定大小的目标
## 二值图像形态学运算小结
- 腐蚀	$A \ominus B$	缩小目标，去除小细节
- 膨胀	$A \oplus B$	扩大目标，填充孔洞
- 开运算	$A \circ B = (A \ominus B) \oplus B$	平滑轮廓，去除凸起
- 闭运算	$A \bullet B = (A \oplus B) \ominus B$	平滑轮廓，填充凹陷
- 击中-击不中	$A \circledast B$	形状匹配与定位
- 边界提取	$\beta(A) = A - (A \ominus B)$	提取目标边界
- 孔洞填充	条件膨胀	填充目标内部孔洞
- 连通分量提取	条件膨胀	提取各个连通目标
- 细化	反复击中-击不中	得到单像素宽骨架
- 骨架	反复开运算与腐蚀	得到中轴骨架
## 灰度级形态学
### 灰度腐蚀和膨胀
#### 灰度腐蚀
- 定义：输出图像中每个像素的值等于结构元覆盖区域内输入图像的最小值
- 效果：使图像变暗，消除亮细节
- 公式： $[f \ominus b](x, y) = \min_{(s,t) \in b} \{ f(x+s, y+t) \}$
#### 灰度膨胀
- 定义：输出图像中每个像素的值等于结构元覆盖区域内输入图像的最大值
- 效果：使图像变亮，消除暗细节
- 公式：$[f \oplus b](x, y) = \max_{(s,t) \in b} \{ f(x+s, y+t) \}$
### 灰度开运算和闭运算
#### 灰度开运算
先腐蚀后膨胀
- 效果：去除小的亮区域，平滑轮廓
- 应用：背景估计、光照校正
#### 灰度闭运算
先膨胀后腐蚀
- 效果：去除小的暗区域，填充孔洞
- 应用：噪声去除、目标增强
### 一些基本的灰度级形态学算法
- 形态学梯度	边缘检测， $g = (f \oplus b) - (f \ominus b)$
- 顶帽变换	提取亮细节， $f - (f \circ b)$
- 底帽变换	提取暗细节， $(f \bullet b) - f$
- 对比度增强	同时增强亮和暗细节
### 灰度级形态学重建
- 原理：与二值形态学重建类似，但处理的是灰度级
- 应用：
  - 去除不均匀背景
  - 提取特定灰度的目标
  - 图像分割
# 核心要点总结
- 形态学基础：形态学处理基于结构元在图像中的移动和匹配，通过集合运算改变目标的形状。
- 腐蚀和膨胀：是最基本的形态学运算，腐蚀缩小目标，膨胀扩大目标，两者互为对偶。
- 开运算和闭运算：开运算先腐蚀后膨胀，用于去除小凸起和噪声；闭运算先膨胀后腐蚀，用于填充小孔洞和断裂。
- 击中-击不中变换：用于在图像中定位特定形状，是形状检测和模式识别的工具。
- 基本形态学算法：包括边界提取、孔洞填充、连通分量提取、细化、骨架提取等，是图像分析的重要工具。
- 形态学重建：基于测地膨胀和腐蚀，在掩模限制下进行运算，用于提取特定目标。
- 灰度级形态学：将形态学运算扩展到灰度图像，使用最大值和最小值运算，适用于灰度图像处理。
- 应用场景：形态学处理广泛应用于图像预处理、形状分析、图像分割后处理、纹理分析等领域。
