# 频率域滤波
## 背景
1. 基本概念
- 频率域滤波：在图像的傅里叶变换域中执行滤波操作，然后将结果反变换回空间域。
- 与空间域的关系：空间域和频率域通过傅里叶变换相关联。空间域中的卷积对应频率域中的乘法。
2. 傅里叶系列与变换简史
- 傅里叶级数：任何周期函数都可以表示为不同频率的正弦和余弦函数的加权和。
- 傅里叶变换：将(曲线下方面积有限的)非周期函数用正弦函数和/或余弦函数乘以加权函数的积分表示为连续频谱。
- 离散傅里叶变换（DFT）：适用于数字图像处理，处理离散取样数据。
---

1. 复数
- 形式： $C = R + jI$，其中 $j = \sqrt{-1}$， $R$ 是实部， $I$ 是虚部。
- 复数的共轭： $C^* = R - jI$。
- 复数的模（幅值）： $|C| = \sqrt{R^2 + I^2}$，用极坐标表示复数时，C=|C|(cosθ+jsinθ)=|C|e<sup>jθ<sup> 
2. 傅里叶级数
- 周期为 $T$ 的连续函数 $f(t)$ 可表示为：
$$f(t) = \sum_{n=-\infty}^{\infty} c_n e^{j\frac{2\pi n}{T}t}$$


其中，
$c_n = \frac{1}{T} \int_{-\frac{T}{2}}^{\frac{T}{2}} f(t) e^{-j \frac{2\pi n}{T} t} dt, \quad n = 0, \pm 1, \pm 2, \dots$

3. 冲激函数及其取样性质
- 冲激函数（狄拉克δ函数）： $\delta(t)$ 是广义函数（分布），信号与系统里最核心的工具。
- 性质： $\int_{-\infty}^{\infty} \delta(t) dt = 1$，且对于 $t \neq 0$， $\delta(t) = 0$。
  - 可以想象一个脉冲只在 t=0 这一刻有 “冲击”，其余所有时间都是 0，脉冲持续时间无限短，幅度无限大，但它的面积（积分）等于 1。
- 取样性质：
$$\int_{-\infty}^{\infty} f(t) \delta(t - t_0) dt = f(t_0)$$
  - 冲激搬移到 \(t_0\)，积分就直接取出函数在 \(t_0\) 的函数值。
- 尺度变换：
  - $$\delta(at)=\frac{1}{|a|}\delta(t)$$ 时间拉伸压缩，冲激强度会变。
- 与普通函数相乘
  - 公式： $$f(t) \cdot \delta(t-t_0) = f(t_0) \cdot \delta(t-t_0)$$ 相乘之后，只剩下冲激，冲激的强度等于 f 在该点的取值。
- 冲激串：每隔时间 T，就放一个单位冲激 δ，无穷多个排成一串，用于对连续函数取样的无限周期冲激序列。
$$s_{\Delta T}(t) = \sum_{n=-\infty}^{\infty} \delta(t - n\Delta T)$$
4. 连续单变量函数的傅里叶变换
- 傅里叶变换：
$$F(\mu) = \int_{-\infty}^{\infty} f(t) e^{-j2\pi\mu t} dt$$
- 傅里叶反变换：
$$f(t) = \int_{-\infty}^{\infty} F(\mu) e^{j2\pi\mu t} d\mu$$
- 傅里叶变换对： $f(t) \iff F(\mu)$
5. 卷积
定义： $f(t) \star g(t) = \int_{-\infty}^{\infty} f(\tau) g(t - \tau) d\tau$
- 卷积定理：
  - 空间域卷积 $\iff$ 频率域乘法： $f(t) \star g(t) \iff F(\mu)G(\mu)$
  - 空间域乘法 $\iff$ 频率域卷积： $f(t)g(t) \iff F(\mu) \star G(\mu)$
## 取样与取样函数的傅里叶变换
### 取样（采样）
- 用冲激串 $s_{\Delta T}(t)$ 乘以连续函数 $f(t)$ 得到取样后的函数：
$$\tilde{f}(t) = f(t) s_{\Delta T}(t) = \sum_{n=-\infty}^{\infty} f(t) \delta(t - n\Delta T)$$
- 取样后的函数的傅里叶变换
取样后的函数的傅里叶变换 $\tilde{F}(\mu)$ 是原函数傅里叶变换 $F(\mu)$ 的周期复制，复制间隔为 $1/\Delta T$：
$$\tilde{F}(\mu) = \frac{1}{\Delta T} \sum_{n=-\infty}^{\infty} F(\mu - \frac{n}{\Delta T})$$

#### 取样定理
如果函数 $f(t)$ 是带限的（即其傅里叶变换 $F(\mu)$ 在 $|\mu| > \mu_{\text{max}}$ 时为零），并且取样频率 $\mu_s = 1/\Delta T$ 满足：
$$\mu_s > 2\mu_{\text{max}}$$
则函数可由其取样值完全恢复。
### 混叠
- 奈奎斯特频率：恰好完全恢复函数所需的最小取样频率 $2\mu_{\text{max}}$。
  - 当取样频率低于奈奎斯特频率时，高于奈奎斯特频率 $f_N$ 的频率，会折叠成等效低频，周期复制的频谱会发生重叠，导致混叠。
- 混叠使得无法从取样后的数据中准确恢复原函数。
  - 空间域中的混叠表现为摩尔条纹（伪高频）。
    - 拍摄细密纱窗、格子衬衫、屏幕像素条纹时出现扭曲、流动的彩色波纹，就是二维空间混叠；细密纹理（高频） > 奈奎斯特频率 → 混叠生成虚假低频波纹。
- 数字图像缩小后，混叠通常会变得更严重；
- 在光学中，莫尔模式是由近似等间隔的两个光栅叠加所产生的一种视觉现象。
### 由取样后的数据重建（复原）函数
- 用低通滤波器（理想低通滤波器）对取样后的函数滤波，提取中心周期的频谱，即可恢复原函数。
- 理想低通滤波器的傅里叶反变换是sinc函数，空间域重建对应于用sinc函数内插。
### 单变量的离散傅里叶变换
1. 由取样后函数的连续变换得到DFT
离散傅里叶变换（DFT）是取样后的函数的连续傅里叶变换在频率域中取样得到的。
- 一维DFT：
$$F(\mu) = \sum_{x=0}^{M-1} f(x) e^{-j2\pi\mu x/M}, \quad \mu = 0,1,2,\dots,M-1$$
- 一维IDFT：
$$f(x) = \frac{1}{M} \sum_{\mu=0}^{M-1} F(\mu) e^{j2\pi\mu x/M}, \quad x = 0,1,2,\dots,M-1$$
2. 取样和频率间隔的关系
- 空间域取样间隔为 $\Delta T$，频率域取样间隔为 $\Delta \mu = 1/(M\Delta T)$。
- 频率域中覆盖的范围（频率分辨率）为 $\Omega = M\Delta\mu = 1/\Delta T$。
### 二变量函数的傅里叶变换
1. 二维冲激及其取样性质
- 二维冲激 $\delta(x, y)$：
$$\iint_{-\infty}^{\infty} \delta(x, y) dxdy = 1$$
- 取样性质：
$$\iint_{-\infty}^{\infty} f(x, y) \delta(x - x_0, y - y_0) dxdy = f(x_0, y_0)$$
2. 二维连续傅里叶变换对
- 二维傅里叶变换：
$$F(u, v) = \iint_{-\infty}^{\infty} f(x, y) e^{-j2\pi(ux + vy)} dxdy$$
- 二维傅里叶反变换：
$$f(x, y) = \iint_{-\infty}^{\infty} F(u, v) e^{j2\pi(ux + vy)} dudv$$
3. 二维取样和二维取样定理
- 二维取样函数： $\tilde{f}(x, y) = f(x, y) s_{\Delta X, \Delta Y}(x, y)$
- 二维取样定理：取样频率在两个方向上都必须大于对应方向上最高频率的2倍。
4. 图像中的混叠
- 空间取样不足时，在图像中会产生莫尔条纹等伪影，即混叠效应。
5. 二维离散傅里叶变换及其反变换
- 二维DFT：
$$F(u, v) = \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} f(x, y) e^{-j2\pi(ux/M + vy/N)}$$
- 二维IDFT：
$$f(x, y) = \frac{1}{MN} \sum_{u=0}^{M-1} \sum_{v=0}^{N-1} F(u, v) e^{j2\pi(ux/M + vy/N)}$$
### 二维DFT和IDFT的一些性质
1. 空间间隔和频率间隔的关系
空间域取样间隔 $\Delta X$、 $\Delta Y$，频率域取样间隔： $\Delta u = 1/(M\Delta X)$， $\Delta v = 1/(N\Delta Y)$。
2. 平移和旋转
- 平移：
$f(x - x_0, y - y_0) \iff F(u, v) e^{-j2\pi(ux_0/M + vy_0/N)}$
$f(x, y) e^{j2\pi(u_0 x/M + v_0 y/N)} \iff F(u - u_0, v - v_0)$
- 旋转：空间域旋转 $\theta$ 角度，频率域也旋转相同的角度。
3. 周期性
- DFT和IDFT在 $u$和 $v$方向上具有周期性，周期为$M$和$N$。
- 为了方便显示，通常将频谱中心移至 $(M/2, N/2)$，即使用 $f(x, y)(-1)^{x+y}$的DFT。
4. 对称性
- $f(x, y)$是实函数时， $F(u, v)$是共轭对称的： $F(u, v) = F^*(-u, -v)$。
- 实函数的傅里叶变换的幅度是偶函数，相位是奇函数。
5. 傅里叶频谱和相角
- 傅里叶频谱（幅度谱）： $|F(u, v)| = \sqrt{R^2(u, v) + I^2(u, v)}$
- 相角（相位谱）： $\phi(u, v) = \arctan\left[\frac{I(u, v)}{R(u, v)}\right]$
- 功率谱： $P(u, v) = |F(u, v)|^2$
6. 二维离散卷积定理
- 空间域卷积 $\iff$ 频率域乘法：
$$f(x, y) \star h(x, y) \iff F(u, v)H(u, v)$$
- 空间域乘法 $\iff$ 频率域卷积：
$$f(x, y)h(x, y) \iff F(u, v) \star H(u, v)$$
### 频率域滤波基础
1. 频率域的其他特性
- 低频分量对应图像中灰度变化缓慢的区域（平滑区域、背景）。
- 高频分量对应图像中灰度变化剧烈的区域（边缘、噪声、细节）。
2. 频率域滤波基础知识
- 滤波公式： $G(u, v) = H(u, v)F(u, v)$， 
$F(u, v)$：输入图像的傅里叶变换
$H(u, v)$：滤波器（传递函数）
$G(u, v)$：滤波后的傅里叶变换
- 输出图像： $g(x, y) = \mathcal{F}^{-1}[G(u, v)]$
3. 频率域滤波步骤小结
---
1. 输入图像 $f(x, y)$，大小为 $M \times N$。
2. 对图像填充零至 $P \times Q$，其中 $P = 2M$，$Q = 2N$。
3. 用 $(-1)^{x+y}$ 乘以填充后的图像，将频谱中心移到 $(\frac{P}{2}, \frac{Q}{2})$。
4. 计算DFT，得到 $F(u, v)$。
5. 生成滤波器 $H(u, v)$，大小为 $P \times Q$。
6. 计算 $G(u, v) = H(u, v)F(u, v)$。
7. 计算IDFT，得到 $g(x, y)$。
8. 提取左上角 $M \times N$ 区域，得到滤波后的图像。
---
4. 空间域和频率域滤波之间的对应关系
- 空间域滤波器 $h(x, y)$ 和频率域滤波器 $H(u, v)$ 通过傅里叶变换对关联。
- 空间域中的小尺寸滤波器核对应频率域中的大尺寸滤波器。
- 空间域滤波适合于小尺寸核，频率域滤波适合于大尺寸滤波器。
## 使用低通频率域滤波器平滑图像
1. 理想低通滤波器（ILPF）
定义：$H(u, v) = \begin{cases} 1 & D(u, v) \leq D_0 \\ 0 & D(u, v) > D_0 \end{cases}$
$D(u, v) = \sqrt{(u - P/2)^2 + (v - Q/2)^2}$（中心化后的距离）
$D_0$：截止频率
缺点：在截止频率处引入振铃效应。
2. 高斯低通滤波器（GLPF）
定义： $H(u, v) = e^{-D^2(u, v) / 2D_0^2}$
优点：平滑且无振铃效应。
3. 巴特沃斯低通滤波器（BLPF）
定义： $H(u, v) = \frac{1}{1 + [D(u, v) / D_0]^{2n}}$
$n$：滤波器的阶数
特点：介于理想和高斯滤波器之间，阶数越高，振铃越明显。
九、使用高通滤波器锐化图像（4.9）
1. 由低通滤波器得到高通滤波器
高通滤波器 = 1 - 低通滤波器
高通滤波器衰减低频分量，保留高频分量。
2. 理想高通滤波器
$H(u, v) = \begin{cases} 0 & D(u, v) \leq D_0 \\ 1 & D(u, v) > D_0 \end{cases}$
3. 高斯高通滤波器
$H(u, v) = 1 - e^{-D^2(u, v) / 2D_0^2}$
4. 巴特沃斯高通滤波器
$H(u, v) = \frac{1}{1 + [D_0 / D(u, v)]^{2n}}$
5. 频率域中的拉普拉斯
频率域拉普拉斯滤波器： $H(u, v) = -4\pi^2(u^2 + v^2)$
锐化公式： $g(x, y) = \mathcal{F}^{-1}[F(u, v) - H(u, v)F(u, v)]$
6. 钝化掩蔽、高提升滤波和高频强调滤波
钝化掩蔽： $g(x, y) = f(x, y) - \text{模糊后的图像}$
高提升滤波： $g(x, y) = f(x, y) + k \cdot [f(x, y) - \text{模糊后的图像}]$
$k \ge 0$ 为权重系数
高频强调滤波： $H(u, v) = a + b \cdot H_{\text{hp}}(u, v)$
其中 $a$ 控制低频分量， $b$ 控制高频分量的增强程度。
7. 同态滤波
- 原理：将图像表示为照射分量和反射分量的乘积，取对数后分离，在频率域中进行处理。
- 照射分量（低频）和反射分量（高频）可分别处理。
- 应用：同时压缩动态范围（压缩低频）和增强对比度（增强高频）。
十、选择性滤波（4.10）
1. 带阻滤波器和带通滤波器
- 带阻滤波器：阻止/衰减特定频率范围内的频率分量。
- 带通滤波器：允许特定频率范围内的频率分量通过。
- 带通滤波器 = 1 - 带阻滤波器
2. 陷波滤波器
- 用于阻止（或允许）特定频率点的频率分量。
- 常用于去除周期性噪声（如正弦干扰）。
- 陷波滤波器 = 1 - 带阻滤波器（在特定频率点处）
十一、快速傅里叶变换FFT（4.11）
1. 二维DFT的可分离性
二维DFT可分解为两个一维DFT：
$$F(u, v) = \sum_{x=0}^{M-1} \left[\sum_{y=0}^{N-1} f(x, y) e^{-j2\pi vy/N}\right] e^{-j2\pi ux/M}$$
先对每一行计算一维DFT，再对每一列计算一维DFT。
2. 使用DFT算法计算IDFT
IDFT可通过DFT计算：
$$f(x, y) = \frac{1}{MN} \overline{\mathcal{F}[\overline{F(u, v)}]}$$
其中 $\overline{\cdot}$ 表示复共轭。
3. 快速傅里叶变换（FFT）
FFT是一种高效计算DFT的算法。
对于长度为 $M$ 的序列，直接计算DFT需要 $O(M^2)$ 次运算，FFT只需 $O(M \log_2 M)$ 次运算。
常见的FFT算法是库利-图基算法，基于将DFT分解为奇偶子序列。
核心要点总结
频率域滤波的核心思想：图像在频率域中，低频对应平滑区域，高频对应边缘和噪声，通过修改频谱可实现图像平滑、锐化和去噪。
取样定理：为避免混叠，取样频率必须大于或等于信号最高频率的2倍（奈奎斯特频率）。
DFT的性质：平移、旋转、周期性、对称性和卷积定理是频率域滤波的基础。
低通滤波器：平滑图像，衰减高频（噪声、细节），高斯低通滤波器无振铃效应。
高通滤波器：锐化图像，增强边缘，常与低通滤波器互补。
同态滤波：同时处理照射分量和反射分量，用于光照校正和增强对比度。
选择性滤波：陷波滤波器专门用于去除周期性噪声。
FFT：大幅降低计算复杂度，使频率域滤波在实际应用中可行。
