# 图像压缩和水印

图像压缩是数字图像处理中的一个重要领域，其目标是减少表示图像所需的数据量，以便更有效地存储和传输。
本章首先介绍数据压缩的基础知识，包括数据冗余的类型、信息度量、保真度准则和压缩模型，然后详细讨论多种具体的压缩编码技术，最后介绍数字图像水印技术。
## 基础
### 编码冗余
编码冗余是指用于表示图像灰度级的编码比特数多于实际所需比特数的情况。

- 灰度级直方图： $p_r(r_k) = n_k / MN$，其中 $n_k$ 是灰度级 $r_k$ 出现的次数， $MN$ 是像素总数
- 平均码字长度： $L_{\text{avg}} = \sum_{k=0}^{L-1} l(r_k) p_r(r_k)$，其中 $l(r_k)$ 是码字长度
- 目的：最小化 $L_{\text{avg}}$，使编码效率接近熵
#### 空间冗余和时间冗余
- 空间冗余（帧内冗余）：图像中相邻像素之间的相关性
- 时间冗余（帧间冗余）：视频序列中相邻帧之间的相关性
两种冗余都源于像素间的相关性，可通过预测编码等方法消除
### 无关信息
- 无关信息：人眼感知不到或不敏感的图像信息
- 丢弃无关信息可实现有损压缩，且视觉质量下降不明显
- 利用人类视觉系统（HVS）的特性
### 度量图像信息
- 熵（信息量）： $H = -\sum_{k=0}^{L-1} p_r(r_k) \log_2 p_r(r_k)$（比特/像素）
- 熵是编码所需的最小平均比特数下界
- 熵编码的目标是使平均码长接近熵
### 保真度准则
| 准则类型	| 示例	| 特点 |
| ---- | ---- | ---- |
| 客观保真度准则	| 均方根误差（RMS）、信噪比（SNR）|	可量化计算|
| 主观保真度准则	| 观察者评分	| 反映人眼感知|
### 图像压缩模型
- 编码器：由映射器（变换）、量化器（有损）和符号编码器组成
- 解码器：由符号解码器和逆映射器组成
- 压缩过程：原图像 → 映射 → 量化 → 符号编码 → 压缩数据
- 解压缩过程：压缩数据 → 符号解码 → 逆映射 → 重建图像
### 图像格式、存储器和压缩标准
- 常见图像格式：BMP、TIFF、JPEG、GIF、PNG
- 压缩标准：JPEG（静态图像）、MPEG（视频）、JPEG-2000
## 霍夫曼编码
### 基本原理
- 变长编码：出现概率高的符号用短码字，概率低的符号用长码字
- 前缀码：没有一个码字是其他码字的前缀，确保唯一可译性
- 最优性：霍夫曼编码生成最小冗余度的前缀码
### 编码步骤
1. 将符号按概率降序排列
2. 合并两个最小概率的符号，形成新节点，概率相加
3. 重复步骤1-2，直到只剩一个节点（根节点）
4. 从根节点回溯，分配码字（如左分支为0，右分支为1）
#### 特点
- 编码效率高，接近熵
- 需要知道符号的概率分布
- 静态霍夫曼编码需要两遍扫描（一遍统计，一遍编码）
## Golomb编码
- 用于编码非负整数，参数为 $m$
- 编码由两部分组成：
  - 一元编码：商 $q = \lfloor n/m \rfloor$，用 $q$ 个1后跟一个0表示
  - 余数编码：余数 $r = n \bmod m$，用 $\lceil \log_2 m \rceil$ 或 $\lfloor \log_2 m \rfloor$ 比特表示
- 特点：适用于几何分布的数据，计算简单，无需查表，在JPEG-LS中使用
五、8.4 算术编码
基本原理
将整个消息序列映射为区间 $[0](@ref)[1](@ref)$ 中的一个实数
编码过程：根据符号概率逐步缩小区间
解码过程：根据区间位置确定符号序列
自适应上下文相关概率估计
不需要预先知道符号概率分布
在编码过程中动态更新概率估计
上下文模型利用相邻符号的相关性
特点
编码效率接近熵，可达到分数比特/符号
优于霍夫曼编码（尤其是符号概率接近时）
在JPEG-2000和H.264中使用
六、8.5 LZW编码
基本原理
字典编码：将输入序列中的重复模式替换为字典索引
编码器和解码器动态构建相同的字典
初始字典包含所有单个符号
编码过程
初始化字典（包含所有单个符号）
读取输入序列的最长匹配前缀
输出该前缀的字典索引
将匹配前缀加上下一个符号加入字典
重复步骤2-4
特点
无损压缩
对重复模式多的数据效果好
在GIF和TIFF格式中使用
七、8.6 行程编码
基本原理
将连续相同值的序列（行程）编码为（值，长度）对
适用于二值图像或灰度变化缓慢的图像
一维CCITT压缩
用于传真机的二值图像压缩标准
对黑白行程分别编码
使用霍夫曼编码表（基于统计的固定码表）
二维CCITT压缩
利用上一行的信息
编码当前行相对于上一行的变化（如位置变化）
比一维压缩效率更高
特点
对二值图像效果极好
简单快速
对灰度图像效果一般
八、8.7 基于符号的编码
基本原理
将图像分解为符号（字符、图案）
每个符号作为独立单元编码
适用于包含重复文本或图案的图像
JBIG2压缩
二值图像压缩标准
基于符号的编码方法
对文档图像（如扫描的文本）效果极好
支持无损和有损压缩
九、8.8 比特平面编码
基本原理
将灰度图像分解为多个比特平面
每个比特平面是二值图像
对比特平面分别编码
分解方法
灰度编码：$g_i = b_i \oplus b_{i+1}$，其中 $b_i$ 是原比特，$g_i$ 是格雷码比特
格雷码编码的好处：相邻灰度级的比特平面变化更少
编码方法
对比特平面使用行程编码
或使用其他二值图像编码方法
特点
适用于图像渐进传输
高比特平面包含更多重要信息
十、8.9 块变换编码
8.9.1 变换的选择
离散余弦变换（DCT）：JPEG压缩标准的核心
DCT将图像能量集中到低频系数
高频系数可被量化或丢弃，视觉质量损失小
8.9.2 子图像尺寸选择
典型子图像大小为 $8 \times 8$ 或 $16 \times 16$ 像素
子图像过大可能导致相关性消失
子图像过小则压缩效率低
8.9.3 比特分配
比特分配：为每个变换系数分配不同数量的比特
低频系数分配更多比特，高频系数分配更少比特
使用Z字形扫描将二维DCT系数转换为一维序列
特点
JPEG标准的核心技术
在中等压缩比下提供良好质量
在较高压缩比下可能出现块效应
十一、8.10 预测编码
8.10.1 无损预测编码
预测器：基于前几个像素预测当前像素值
预测误差：$e = f - \hat{f}$，其中 $\hat{f}$ 是预测值
对预测误差进行熵编码
预测越准确，误差越小，压缩率越高
8.10.2 运动补偿预测残差
用于视频压缩
在帧间预测中，对当前块相对于参考帧的位移进行估计
编码运动矢量和预测残差
8.10.3 有损预测编码
在预测编码中添加量化步骤
量化预测误差，引入失真
使用DPCM（差分脉冲编码调制）
8.10.4 最优预测器
基于最小均方误差（MMSE）准则
预测系数通过解Yule-Walker方程得到
预测器阶数越高，预测越准确，但计算复杂度也越高
8.10.5 最优量化
Lloyd-Max量化器：最小化量化误差的均方值
量化级数决定压缩比和失真程度
十二、8.11 小波编码
8.11.1 小波的选择
小波基函数的选择影响压缩性能
常用小波：Daubechies小波、双正交小波
JPEG-2000使用Cohen-Daubechies-Feauveau（CDF）9/7小波
8.11.2 分解级数的选择
分解级数越多，能量集中性越好
但分解级数过多会导致计算复杂度增加
典型分解级数为3-5级
8.11.3 量化器设计
使用嵌入量化（嵌入式零树编码）
渐进式编码：先传输重要系数，再传输细节
支持渐进传输和分辨率可伸缩
8.11.4 JPEG-2000
JPEG-2000：基于小波变换的图像压缩标准
支持无损和有损压缩
支持渐进传输（按质量、分辨率、空间位置）
无块效应，质量优于JPEG
核心算法：EBCOT（嵌入式块编码优化截断）
应用：医学图像、数字影院、遥感图像
十三、8.12 数字图像水印
基本原理
数字水印：将不可见的信息嵌入图像中
目的：版权保护、内容认证、完整性验证
水印可以是有形的（如可见水印）或无形的（如不可见水印）
水印类型
类型	特点	应用
可见水印	人眼可察觉	预览、版权声明
不可见水印	人眼不可察觉	版权保护、隐秘通信
鲁棒水印	抵抗攻击（压缩、裁剪等）	版权保护
脆弱水印	对篡改敏感	内容认证
水印嵌入方法
空间域：直接修改像素值（如LSB替换）
变换域：在DCT、DWT或DFT系数中嵌入
扩频水印：将水印信号扩展到整个图像
水印检测
检测水印的存在性
提取水印内容
相关性检测或匹配滤波
十四、核心要点总结
数据压缩基础：压缩通过消除编码冗余、空间/时间冗余和无关信息来实现，熵是编码效率的理论下限。
霍夫曼编码：最优前缀码，编码效率接近熵，但需要知道符号概率分布。
算术编码：接近熵编码效率，支持自适应概率估计，优于霍夫曼编码。
LZW编码：字典编码，适用于重复模式多的数据，无损压缩。
行程编码：对二值图像和灰度变化缓慢的图像效果极好。
块变换编码：JPEG标准的核心，使用DCT变换和Z字形扫描，中等压缩比下质量良好。
预测编码：利用像素间的相关性，预测误差越小，压缩率越高。
小波编码：JPEG-2000标准的核心，无块效应，支持渐进传输，质量优于JPEG。
数字水印：用于版权保护和内容认证，分为鲁棒水印和脆弱水印。
一句话总结：第八章系统介绍了图像压缩的基本原理（数据冗余、信息度量、保真度准则）和多种编码技术（霍夫曼编码、算术编码、DCT编码、小波编码等），最后介绍了数字水印技术的原理和应用。
