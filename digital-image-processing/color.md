# 彩色图像处理

彩色图像处理是数字图像处理中的一个重要领域，其重要性源于两个主要原因：
1. 首先，彩色是一种强大的描述子，能够简化目标识别和提取；
2. 其次，人类可以辨别数千种颜色和强度，相比之下只能辨别约20种灰度。
| 类型	| 数量	| 功能 |	分布特点 |
| ---- | ---- | ---- | ---- |
| 锥状体 |	600~700万	| 对颜色高度敏感，提供明视觉（亮视觉）|	主要分布在中央凹，分辨率高 |
| 杆状体	| 7500~15000万	| 对低光照度敏感，无彩色感，提供暗视觉（微光视觉）|	分布面积大，分辨率低 |
## 彩色基础
1. 颜色的基本属性
- 颜色本质：可见光是电磁波谱中波长范围约为0.43μm（紫色）到0.79μm（红色）的波段
- 物体颜色：由物体反射的光的性质决定
相对平衡地反射所有可见光波长的物体呈白色或灰色，以有限范围反射光的物体呈现特定颜色。
2. 彩色光源的三个基本量
| 量	| 定义	| 单位 |
| ---- | ---- | ---- |
| 辐射	| 从光源流出的总能量	| 瓦特（W）|
| 光通量	| 观察者从光源感知的能量 |	流明（lm）|
| 亮度	| 光感知的主观描绘子，体现强度的无色概念 |	不可度量 |
3. 三原色与三基色
- 三原色：红（R）、绿（G）、蓝（B）
- 人类视觉系统对红、绿、蓝光敏感，通过三者的组合可感知各种颜色，其中人眼的锥状体的大部分对红色光敏感，其次是绿色光，但蓝色锥状体对蓝色光更敏感。
- 三基色：青（C）、品红（M）、黄（Y）——RGB的补色
> - 色调（Hue）：与颜色纯度相关的属性，用于描述主色（如红色、绿色、蓝色）。在HSI模型中，色调分量（H）携带了主要的颜色信息。
> - 亮度：发光强度的消色概念。
> - 饱和度（Saturation）：指颜色被白色稀释的程度。纯色的饱和度最高，白色的饱和度最低。在HSI模型中，饱和度分量（S）描述了颜色的纯度或鲜艳程度。
> - 色度（Chromaticity）：它通常指由色调和饱和度共同决定的颜色属性，即不包含亮度信息的颜色特性。CIE色度图就是用于精确指定彩色光的色度值的工具。
4. 色度图
- CIE色度图：1931年由国际照明委员会（CIE）制定
- 用途：精确指定彩色光
- 特性：
  - 显示所有可见颜色的色度值
  - 边界上的点表示纯光谱色（单色光）
  - 连接两端点的直线称为紫色线，紫色线中的颜色不是光谱色
- 任意两种颜色的混合色位于连接这两种颜色的直线上
- 颜色互补：色度图上通过白色点（如C点）的直线两端对应的颜色互为补色。
## 彩色模型
### RGB彩色模型
- 原理：基于红、绿、蓝三原色，每种颜色用三个分量表示
- 表示方式：RGB彩色立方体，三个轴分别对应R、G、B
- 坐标约定：
  - 黑色位于原点(0,0,0)
  - 白色位于(1,1,1)（归一化后）
  - 灰度值沿从原点到白色点的对角线上分布
- 应用：彩色监视器、彩色摄像机等硬件设备
### CMY和CMYK彩色模型
- CMY模型：青（Cyan）、品红（Magenta）、黄（Yellow）
- 与RGB的转换：使用补色关系
- 公式：C = 1 - R, M = 1 - G, Y = 1 - B（归一化后）
- CMYK模型：CMY + K（黑色）
- 添加黑色的原因：CMY混合产生的黑色不够纯
- 用于彩色打印设备
### HSI彩色模型
- HSI模型：色调（Hue）、饱和度（Saturation）、亮度（Intensity）
- 特点：更符合人类视觉感知颜色的方式
| 分量	| 定义	| 物理意义|
|----|----|----|
| 色调(H)	| 颜色纯度的属性，描述主色	| 如红色、绿色、蓝色|
| 饱和度(S)	| 颜色被白色稀释的程度	| 纯色饱和度最高，白色饱和度最低|
| 亮度(I)	| 颜色的明亮程度	| 与图像灰度相关|
- HSI与RGB的转换：可通过公式相互转换
- 优势：将颜色信息（H、S）与亮度信息（I）分离，便于处理
### 设备无关彩色模型
- 为在不同设备间保持颜色一致性而设计
- 常见模型：CIE Lab、CIE Luv等
- 应用：颜色管理、跨设备颜色匹配
## 假彩色图像处理
### 基本概念
- 假彩色：将灰度图像映射为彩色图像的过程
- 目的：增强人眼对灰度细节的辨别能力
- 原理：人眼只能辨别约20种灰度，但能辨别数千种颜色
### 灰度分层和彩色编码
- 方法：将灰度轴划分为多个区间，每个区间映射为一种颜色
- 公式：设灰度范围为[0, L-1]，将其划分为k个区间，每个区间分配一种颜色
- 应用：遥感图像、医学图像增强
### 灰度到彩色的变换
- 方法：使用三个独立的变换函数，将灰度值分别映射为R、G、B分量
公式：
- R(x,y) = T_R[f(x,y)]
- G(x,y) = T_G[f(x,y)]
- B(x,y) = T_B[f(x,y)]
- 特点：可产生丰富的彩色效果
## 全彩色图像处理基础
- 方法一	分别处理每个彩色分量，再组合	简单，但可能产生颜色失真
- 方法二	直接处理彩色向量	理论上更准确，计算复杂

- 对于线性处理，两种方法等价
- 对于非线性处理，方法二更准确
## 彩色变换
1. 公式
彩色变换模型：
$$g(x,y) = T[f(x,y)]$$
其中f和g是彩色向量，T是变换函数
2. 补色
- 定义：彩色环上对立的颜色
- 公式：C = 1 - RGB（归一化后）
- 应用：增强颜色对比度，产生艺术效果
3. 彩色分层
- 目的：突出图像中的特定颜色区域
- 方法一：将感兴趣区域的颜色设为特定颜色，其他设为中性色
- 方法二：在RGB空间或HSI空间中定义颜色范围
4. 色调和彩色校正
- 色调校正：调整图像的整体颜色倾向
- 彩色校正：使图像颜色更接近真实或期望的颜色
- 应用：印刷、显示、摄影中的颜色管理
5. 彩色图像的直方图处理
- 方法：分别在R、G、B分量上应用直方图均衡化
- 问题：可能导致颜色失真（改变颜色平衡）
- 替代方案：在HSI空间中对亮度分量（I）进行直方图处理，保持色调和饱和度不变
## 彩色图像平滑和锐化
### 彩色图像平滑
- 平滑方法：对每个彩色分量分别应用平滑滤波器
- 常用滤波器：均值滤波器、高斯滤波器、中值滤波器
- 注意事项：
  - 在RGB空间中分别平滑每个分量
  - 在HSI空间中只平滑亮度分量（I），保持色调和饱和度不变
### 彩色图像锐化
- 锐化方法：使用拉普拉斯算子、Sobel算子等锐化滤波器
- 重点：在RGB或HSI空间中应用锐化
- 注意：锐化可能引入颜色噪声
## 使用彩色分割图像
### HSI彩色空间中的分割
- 分割依据：色调（H）和饱和度（S）信息
- 步骤：
  - 将RGB图像转换为HSI空间
  - 基于色调范围选择感兴趣区域
  - 使用饱和度阈值排除低饱和度区域（白色、灰色）
  - 生成二值分割掩模
### RGB空间中的分割
- 分割依据：RGB颜色向量间的距离
- 方法：
  - 定义参考颜色向量a
  - 计算每个像素颜色向量z与a的距离
  - 距离小于阈值的像素属于目标区域
  - 距离公式： $D(z,a) = \|z-a\| = [(z-a)^T(z-a)]^{1/2}$
### 彩色边缘检测
- 问题：灰度边缘检测方法不能直接应用于彩色图像
- 方法：
  - 计算每个分量图像的梯度，然后组合
  - 使用向量梯度公式
- 关键点：梯度方向由R、G、B分量的变化共同决定
## 彩色图像中的噪声
- 噪声特性
  - 噪声可能影响一个或多个彩色分量
  - 噪声类型：高斯噪声、椒盐噪声、周期噪声等
| 噪声类型	| 处理方法|
| ---- | ---- |
|独立分量噪声 |	在每个分量上分别滤波 |
| 相关噪声	| 考虑分量间的相关性处理|
| 脉冲噪声	| 中值滤波（分别处理或向量处理）|
## 彩色图像压缩
- 压缩原因：彩色图像数据量远大于灰度图像
- 压缩方法：
  - 利用人眼对颜色细节不敏感的特性
  - 对亮度分量（Y）使用高分辨率编码
  - 对色度分量（Cb、Cr）使用低分辨率编码
- 标准：JPEG压缩标准
## 核心要点总结
- 彩色基础：颜色由物体反射的光波长决定，RGB三原色是所有彩色模型的基础
- 彩色模型：
  - RGB：面向硬件，彩色监视器使用
  - CMY/CMYK：面向打印，添加黑色(K)使黑色更纯
  - HSI：面向人类感知，将颜色（H、S）与亮度（I）分离
- 假彩色处理：增强灰度图像的可视化，利用人眼对颜色敏感的特性
- 全彩色处理：可分别处理分量或直接处理向量，线性处理时两种方法等价
- 彩色变换：补色、彩色分层、色调校正可用于图像增强和颜色调整
- 彩色图像分割：可在HSI空间（基于色调）或RGB空间（基于距离）进行
- 彩色边缘检测：需要特殊处理，不能简单套用灰度方法
- 噪声处理：可在各分量上分别处理，或使用向量滤波方法
- 压缩：利用人眼对色度不敏感的特性，对亮度分量保留更多细节
