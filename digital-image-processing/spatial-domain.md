> 本章讨论的所有图像处理技术都是在空间域中实现的。空间域是包含图像中像素的平面，空间域技术直接操作图像中的像素。

空间域处理基于表达式：
$$g(x,y) = T[f(x,y)]$$
> 其中， $f(x,y)$是输入图像， $g(x,y)$是输出图像， $T$是在点 $(x,y)$的一个邻域上定义的针对 $f$的算子。

### 空间域图像处理的两个主要类别

| 类别	| 操作对象	| 典型应用 |
| ---- | ---- | ---- |
| 灰度变换	| 单像素操作（点处理）|	对比度拉伸、阈值处理 |
| 空间滤波	| 像素邻域操作 | （邻域处理） |	图像平滑、图像锐化 |

## 灰度变换和空间滤波基础
核心公式： $g(x,y) = T[f(x,y)]$

两种处理方式：
- 点处理：邻域大小为 $1 \times 1$， $g$只依赖于 $(x,y)$处的 $f$值， $T$称为灰度变换函数：
$$s = T(r)$$
  - $s$和 $r$分别表示 $g$和 $f$在任意点 $(x,y)$处的灰度
- 邻域处理：邻域中心从一个像素移到另一个像素，将算子 $T$应用到邻域中的像素，在该位置产生输出值

> 本章大多数例子是关于图像增强的
- 增强是面向问题的处理，不存在通用“理论”
- 为目视解译目的处理图像时，观察者是最终“判官”
- 为机器感知目的处理图像时，增强更容易量化
## 基本的灰度变换函数
灰度变换是最简单的图像处理技术。 $T$把像素值 $r$映射为像素值 $s$。对于8比特图像，查找表有256条记录。

### 三类基本函数
| 函数类型	| 子类	| 公式	| 特点 |
| ---- | ---- | ---- | ---- |
| 线性函数	| 恒等变换	| $s = r$	| 输入输出相同 |
| - | 图像反转 | $s = L-1-r$	| 产生照片底片效果，增强暗色区域中的白色/灰色细节 |
| 对数函数	| 对数变换	| $s = c\log(1+r)$	| 扩展暗像素值，压缩高灰度级值 |
| - | 反对数变换	| 指数形式 | 功能与对数变换相反 |
| 幂律函数	| 伽马变换	| $s = cr^\gamma$	| 改变 $\gamma$值得到一族变换曲线 |
#### 图像反转
- 公式： $s = L - 1 - r$
- 应用：增强图像暗色区域中的白色或灰色细节,结果类似于照片底片
#### 对数变换
- 公式： $s = c\log(1+r)$， $c$为常数， $r \ge 0$
- 特点：将输入中较窄范围的低灰度值映射为输出中较宽范围的灰度级
- 重要性质：压缩像素值的动态范围
- 应用：显示傅里叶频谱（值域很大时）
#### 幂律（伽马）变换
- 公式： $s = cr^\gamma$，$c$和$\gamma$是正常数
- 曲线特性：
  - $\gamma < 1$：将较窄范围的暗输入值映射为较宽范围的输出值
  - $\gamma > 1$：效果与 $\gamma < 1$相反
  - $\gamma = 1$：简化为恒等变换
#### 伽马校正
用于校正设备（如CRT显示器）的幂律响应
- 校正过程：在将图像输入显示设备之前，使用 $s = r^{1/\gamma}$预处理图像
#### 分段线性变换函数
- 优点：形式可以任意复杂
- 缺点：要求用户输入很多参数

1. 对比度拉伸
- 扩展图像中的灰度级范围，使其覆盖整个理想灰度范围
- 典型变换函数：由点 $(r_1, s_1)$和 $(r_2, s_2)$控制形状
- 特殊情形： $r_1 = r_2, s_1 = 0, s_2 = L-1$ 时变为阈值处理函数
2. 灰度级分层
- 目的：突出图像中的特定灰度区间
- 两种基本方法： 
  - 方法一	感兴趣范围显示为白色，其他显示为黑色	二值图像
  - 方法二	使期望灰度范围变亮/变暗，保持其他灰度不变	保留部分灰度
3. 比特平面分层
- 8比特图像可视为由8个1比特平面组成
- 比特平面8（最高有效比特）包含最具视觉意义的数据
## 直方图处理
### 直方图均衡化
- 基本概念：灰度级 $r_k$在图像中出现的概率： $p_r(r_k) = n_k/MN$, $n_k$是灰度级 $r_k$在图像中出现的次数， $MN$是像素总数
- 均衡化变换：
 $$s_k = T(r_k) = \sum_{j=0}^{k} p_r(r_j) = \sum_{j=0}^{k} \frac{n_j}{MN}$$

- 关键性质：
变换 $T(r)$满足： $T(r)$是单调递增函数（保证灰度级顺序不变）, $T(r)$的取值范围为 $[0, L-1]$
- 直方图均衡化自动确定变换函数，产生灰度级分布均匀的输出图像
### 直方图匹配（规定化）
- 定义：将直方图变换为指定形状的处理方法
- 步骤：
  - 计算输入图像的直方图均衡化变换
  - 计算指定直方图的均衡化变换
  - 将步骤1的结果映射到步骤2的逆变换
### 局部直方图处理
- 定义：基于像素邻域的灰度分布来设计变换函数
- 方法：定义邻域，在邻域内进行直方图均衡化
### 使用直方图统计量增强图像
- 均值： $m = \sum_{k=0}^{L-1} r_k p(r_k)$
- 方差： $\sigma^2 = \sum_{k=0}^{L-1} (r_k - m)^2 p(r_k)$
- 应用：基于局部均值和方差进行自适应增强
## 空间滤波基础
### 线性空间滤波的原理
#### 核心概念
- 滤波器核（掩模、模板、窗口）：一个小的二维阵列
- 滤波过程：在图像中逐点移动核，在每个点$(x,y)$处，滤波器在该点的响应是核与通过核的图像像素的乘积之和
#### 相关与卷积
- 相关：滤波器核在图像上滑动，计算核与图像像素的乘积之和	核不旋转
- 卷积：先将核旋转180°，再进行相关运算	核需要旋转
#### 可分离滤波器核
- 定义：如果核 $w$可以表示为两个向量的乘积： $w = vw^T$，则称核是可分离的
- 优点：可分离核可以分解为两个一维滤波器的顺序应用，提高计算效率

### 平滑（低通）空间滤波器
#### 盒式滤波器核
- 所有系数相等，输出是邻域内像素的平均值
- 缺点：会产生模糊，且对噪声敏感
#### 低通高斯滤波器核
- 核的系数由高斯函数确定
- 特点：中心权重最大，向边缘逐渐减小
- 应用：图像平滑、降噪
#### 统计排序（非线性）滤波器
- 中值滤波器：用邻域内像素的中值代替中心像素的值
  - 特点：对椒盐噪声的抑制效果很好，且比同样大小的均值滤波器产生的模糊更少
### 锐化（高通）空间滤波器
- 锐化处理：增强图像中的边缘和细节
- 基于微分运算：一阶导数和二阶导数
#### 使用二阶导数锐化图像——拉普拉斯
- 拉普拉斯算子： $\nabla^2 f = \frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2}$
- 离散形式： $\nabla^2 f = f(x+1,y) + f(x-1,y) + f(x,y+1) + f(x,y-1) - 4f(x,y)$
- 锐化公式： $g(x,y) = f(x,y) - \nabla^2 f(x,y)$
### 钝化掩蔽和高提升滤波
#### 钝化掩蔽：
- 模糊原图像
- 从原图像中减去模糊图像（得到差值图像）
- 将差值图像加到原图像上
- 高提升滤波： $g_{mask} = f(x,y) + k \cdot g_{mask}(x,y)$， $k$是权重系数，$k \ge 0$
#### 使用一阶导数锐化图像——梯度
- 梯度算子： $\nabla f = \begin{bmatrix} G_x \\ G_y \end{bmatrix} = \begin{bmatrix} \frac{\partial f}{\partial x} \\ \frac{\partial f}{\partial y} \end{bmatrix}$
- 梯度幅值： $\nabla f = \sqrt{G_x^2 + G_y^2}$
- 常用算子：Sobel算子、Roberts交叉梯度算子
## 低通、高通、带阻和带通滤波器
滤波器类型	作用	效果
低通滤波器	衰减高频分量	平滑、模糊、降噪
高通滤波器	衰减低频分量	锐化、增强边缘
带阻滤波器	衰减特定频率范围	去除特定频率干扰
带通滤波器	保留特定频率范围	提取特定频率信息
## 组合使用空间增强方法
单一增强方法通常不足以解决复杂问题
需要组合使用多种技术
典型流程：先平滑降噪，再锐化增强边缘，最后进行对比度调整

## 核心要点总结
灰度变换是点处理技术，直接对每个像素的灰度值进行操作，是最简单的图像处理技术
幂律（伽马）变换是最通用的灰度变换函数，通过改变$\gamma$值可以实现不同的效果
直方图均衡化自动确定变换函数，使输出图像的灰度级分布均匀，增强对比度
空间滤波基于像素邻域操作，分为平滑（低通）和锐化（高通）两大类
相关与卷积是线性空间滤波的两种基本运算，卷积需要将核旋转180°
中值滤波器是统计排序滤波器的典型代表，对椒盐噪声抑制效果很好
钝化掩蔽是一种有效的锐化技术，通过从原图像中减去模糊图像来增强边缘
单一增强方法通常不足以解决复杂问题，需要组合使用多种技术
